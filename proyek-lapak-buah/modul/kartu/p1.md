### Poin kunci (ucapkan)

- Module hanya jalan lewat `http://`. Browser memblokir module dari `file://` (origin `null`).
- `id` untuk JavaScript (satu elemen). `class` untuk CSS (banyak elemen).
- `var(--aksi)`: ubah sekali, berlaku di semua tempat. Mode gelap nanti cukup menimpa variabel.
- Flex = satu arah. Grid = dua arah.
- `data.js` hanya data: harga **number tanpa titik**, `id` unik, ada produk `stok: 0`.

### Peragaan (M2)

```css
.header-isi { display: flex;
  justify-content: space-between;
  align-items: center; gap: 12px; }
.tata-letak { display: grid;
  grid-template-columns: minmax(0, 1fr) 360px;
  gap: 32px; }
```

### Tebak dan kunci

- `"18.000" * 2` = **36** (titik dianggap desimal, harga salah 1000 kali tanpa error).
- 200px + padding 20 + border 2: **244px**; dengan `border-box`: **200px**.
- Jumlah kolom `auto-fill minmax(150px,1fr)`, gap 12: 600px = **3**, 300px = **1**.
