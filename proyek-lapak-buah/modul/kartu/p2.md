### Poin kunci (ucapkan)

- Render = bangun **string HTML** dari data, tulis **sekali** ke `innerHTML`.
- `let html = ""` wajib. `let html;` menghasilkan `undefined<article...`.
- Elemen baru ada **setelah** `innerHTML` diisi, jadi event dipasang sesudahnya (M4).
- `innerHTML` hanya untuk data tepercaya. Teks dari pengguna pakai `textContent`.
- `formatRupiah()` tanpa argumen = `"Rp0"` karena parameter default.

### Peragaan (M3)

```js
const buatBaris = (s) => {
  const { nama, nilai } = s;
  return `<li class="${nilai >= 75 ? "lulus" : "remedial"}">${nama}: ${nilai}</li>`;
};
let html = "";
daftar.forEach((s) => { html += buatBaris(s); });
el.innerHTML = html;
```

### Pemanasan dan kunci

- `const { nama, kelas } = { nama: "Rizky", kelas: 11, hobi: "bola" }` → **Rizky 11**
- `["a","b"].forEach((x, i) => console.log(i, x))` → **0 a** lalu **1 b**
- `` `Total: ${3 * 2} item` `` → **Total: 6 item**
- `(32000).toLocaleString("id-ID")` → **"32.000"** (string)

### Checkpoint

- 6 kartu muncul dari `data.js`, kartu statis hilang.
- Ubah `stok` jadi `0`, muat ulang: kartu jadi **Habis** tanpa mengubah kode lain.
- Tes `formatRupiah` ✅.

### Sering error

| Gejala | Perbaikan |
|---|---|
| `Cannot read properties of null` | Id salah, atau elemen belum dirender |
| Masih kartu statis | `mulai()` belum memanggil `renderKatalog()`, cek Console |
| `undefined` di kartu | Lupa `return`, atau ejaan key salah |
| Kartu tidak "Habis" | Ternary `className` belum benar |

### Kalau telat

Tulis satu baris contoh ternary `className` di papan. Sisanya tetap siswa yang mengetik.

### Exit ticket dan kunci

1. `buatKartu` mengembalikan apa? **String HTML.**
2. Kenapa event tak bisa dipasang sebelum `innerHTML` diisi? **Elemen belum ada, `querySelector` mengembalikan `null`.**
3. `formatRupiah()` hasilnya? **`"Rp0"`, parameter default.**
