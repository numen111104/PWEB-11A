### Poin kunci (ucapkan)

- Key `Map` = **object produk** (bukan string). Value = jumlah.
- `has(objekBaru)` = `false`: object dibandingkan **alamat**, bukan isi.
- `Map.forEach((value, key))`, kebalikan `Array.forEach(item, index)`.
- `keranjang.js` tanpa DOM, jadi bisa diuji dengan `node`.
- Alur: ubah data, `renderNota()`, bangun HTML, pasang event tombol baru.

### Peragaan (M5)

```js
const sesi = new Map();
const a = { id: 1 };
sesi.set(a, "Login");
sesi.has(a);          // true
sesi.has({ id: 1 }); // false
sesi.size;            // 1
sesi.forEach((status, user) => {}); // (value, key)
```

### Sering error

| Gejala | Perbaikan |
|---|---|
| `tambahItem` selalu `true` | Cek `jumlahSekarang >= item.stok` |
| Subtotal `NaN` | Parameter tertukar: harus `(jumlah, item)` |
| Tombol nota tak bereaksi | Event belum dipasang ulang, atau id `kurang-${item.id}` tak cocok |
| `has` selalu `false` | Yang dikirim salinan, bukan object produk asli |

### Kalau telat

Utamakan `tambahItem`, `hitungSubtotal`, tampilan daftar. `kurangiItem` dan tombol `-` pindah ke awal P4.

### Exit ticket dan kunci

1. Kenapa `has(objekBaruIsiSama)` `false`? **Beda alamat (referensi).**
2. Urutan parameter `Map.forEach`? **`(value, key)`.**
3. Risiko tanpa cek stok? **Beli melebihi stok.**
