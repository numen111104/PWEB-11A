### Poin kunci (ucapkan)

- `.value` **selalu string**, walau `type="number"`. Pakai `Number()`.
- Ternary bersusun = pola bonus di `challange.js`. Cek batas **terbesar dulu**.
- `73150 % 100 = 50`, jadi total dibulatkan ke 73.100.
- Parameter default boleh function: `fungsiKupon = () => 0`.
- `addEventListener("input", renderKembalian)` **tanpa kurung**: menitipkan function, bukan memanggilnya.
- Stok dikurangi **setelah bayar**, bukan saat masuk nota.

### Kunci hitung tangan

| Subtotal | Diskon | Pembulatan | Total |
|---|---|---|---|
| 60.000 | 0 | 0 | 60.000 |
| 75.000 | 3.750 | 50 | 71.200 |
| 77.000 | 3.850 | 50 | 73.100 |
| 100.000 | 5.000 | 0 | 95.000 |
| 156.000 | 15.600 | 0 | 140.400 |

Kupon 10% pada 80.000: diskon 4.000, kupon 8.000, total **68.000**.

### Tebak dan kunci

- `"100000" + 1` = **"1000001"**; `- 1` = **99999**; `Number("")` = **0**
- `3 * 5 / 100` = 0.15 vs `3 * (5 / 100)` = 0.15000000000000002

### Peragaan (M7, Level 2)

```js
const buatPajak = (p) => (harga) => harga * p / 100;
const ppn11 = buatPajak(11);
ppn11(100000);                 // 11000
daftar.get("PPN11")(100000);  // dari Map
```

### Uji bayar

- Nota kosong: pesan nota kosong.
- Apel 3 kg + Anggur 1 kg = 156.000. Bayar 100.000: **kurang 40.400**. Bayar 150.000: **kembalian 9.600**.
- Setelah bayar: nota kosong, stok kartu berkurang.

### Sering error

| Gejala | Perbaikan |
|---|---|
| Kembalian `"1000001000"` | Lupa `Number()` |
| Diskon selalu 0 | Urutan ternary: cek 150.000 dulu |
| Total `NaN` atau `undefined` | `hitungRingkasan` belum `return` object, atau ejaan key |
| Tes pembulatan ❌ | Lupa `%` |

### Kalau telat

Kupon (4.5) pindah ke P5. Bukan syarat lulus.

### Exit ticket dan kunci

1. `value + 1000` dan `Number(value) + 1000`? **"1000001000" dan 101000.**
2. Ternary diskon? **`s >= 150000 ? 10 : s >= 75000 ? 5 : 0`**
3. `73150 % 100`? **50, pembulatan ke bawah Rp100.**
